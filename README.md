# Русская Международная Школа в Дубае

Готовый многостраничный сайт на русском языке без внешних JavaScript-зависимостей. Восемь основных страниц, 38 профилей сотрудников, три подробные новости, галерея и страница 404. Фотографии и шрифты хранятся в проекте. Исходный официальный сайт: https://dubairuschool.com/.

## Запуск и обновление

Нужен Node.js 22 или новее. Из папки проекта:

```text
npm run build
npm test
npm run dev
```

Локальный адрес: http://127.0.0.1:4173. Готовые страницы и ресурсы находятся в `dist/`. Для размещения на другом домене измените `origin` в `build.mjs` и пересоберите сайт. Статический сервер должен поддерживать `index.html` в папках и `404.html` для неизвестных адресов.

Повторяемые данные, оригинальные URL фотографий, новости и профили находятся в `content.json`. Страницы создаёт один общий генератор `build.mjs`; стили и интерактивные сценарии находятся в `dist/assets/`.

## GitHub Pages

В проект добавлен `.github/workflows/pages.yml`: он собирает сайт, запускает проверки и публикует только `dist/` при обновлении ветки `main`. В настройках репозитория GitHub → Pages нужно выбрать Source: GitHub Actions. Адрес публикации определяется автоматически, включая путь вида `/russian-school-dubai/`; фотографии, навигация, галерея, карта сайта и канонические адреса учитывают этот путь.

При самостоятельной сборке для другого адреса задайте переменную окружения `SITE_URL` с полным адресом сайта перед запуском `node build.mjs`. Без неё сохраняется существующий адрес Sites. Доступ к репозиторию и запуск в GitHub Actions требуют подключения аккаунта GitHub; наличие файла workflow само по себе не означает, что сайт опубликован.

## Обновлённый дизайн главной

В начале страницы расположены официальная эмблема и полужирное название школы по центру. Прозрачность брендового блока зависит от прокрутки и восстанавливается при возвращении вверх. Компактная навигация остаётся доступной.

Основа страниц использует мягкий бело-сине-красный фон с тремя ограниченными по размеру размытыми CSS-слоями. Слои меняют только положение и прозрачность в циклах 46, 58 и 67 секунд. Светлые разделы полупрозрачны, поэтому фон заметен при прокрутке всех страниц; текст и фотографии не размываются. Внешняя рамка окна и верхняя декоративная полоска удалены. Раздел школьного сообщества содержит 11 небольших декоративных флагов. Перечень стран взят из официальной страницы «Общая информация»: Россия, Беларусь, Казахстан, Узбекистан, Кыргызстан, Таджикистан, Азербайджан, Армения, Туркменистан, Украина и Литва. Статистика национальностей не заявляется. Изображения флагов сохранены локально в `dist/assets/flags/` из SVG FlagCDN (`https://flagcdn.com/{код}.svg`).

Флаги плавно следуют за прокруткой с небольшим смещением; их цикл отрисовки останавливается после затухания движения. При `prefers-reduced-motion` брендовый блок виден, флаги и фон статичны, а необязательные появления отключены. JavaScript не скрывает содержимое до загрузки. Дополнительных библиотек нет.

Мобильная шапка высотой 78 px начинается у верхнего края окна и сохраняет размеры при прокрутке. Служебная полоска на узких экранах скрыта, раскрытое меню ограничено доступной высотой, а при смене режима ширины закрывается. Кнопка меню предшествует ссылкам в порядке клавиатурного обхода. Декоративные стрелки скрыты на мобильных, функциональные кнопки галереи используют SVG. Основной текст использует имеющееся начертание Manrope 500, заголовки — PT Serif 700. Видимый фокус сохранён и окрашен в синий.

Проверки включают границы прогресса прокрутки, затухание брендового блока и статичный режим, все 50 страниц и прежние сценарии поиска и WhatsApp. В браузере проверены восемь разделов при ширинах 360, 390, 768, 1024 и 1440 px: без горизонтальной прокрутки, сломанных изображений и наложений флагов на текст. Также проверены возврат бренда при прокрутке вверх, клавиатурное меню, поиск, пустая выдача, галерея и обязательные поля формы.

## Видеофон первого экрана

На главной странице используется локальный фрагмент школьного ролика https://www.instagram.com/reel/DRdyHnZAvfs/ (13,8–23,8 секунды исходника). Скорость 0,8, цикл 11,25 секунды с переходом 1,25 секунды, H.264 1280×720 / 24 кадра в секунду, без аудиодорожки, 879 444 байта. Постер WebP — 33 334 байта. Размытие и цветовая вуаль применяются только к фоновому слою. Эмблема 175×165 px отображается без увеличения.

Видео приостанавливается кнопкой, вне первого экрана и в скрытой вкладке. При уменьшенном движении исходник не загружается и остаётся постер. При запрете автозапуска доступен ручной запуск, при ошибке видео сохраняется постер. Все страницы используют версии CSS и JavaScript, вычисляемые по содержимому файлов, чтобы обновления не оставались за старым кэшем.

Проверки контроллера включают уменьшенное движение без загрузки видео, ручную паузу и возобновление, сохранение паузы при переключении вкладок, отказ автозапуска и ошибку медиа. Фон ограничен главной страницей. Стык проверен по первому и последнему кадрам и сравнён с изменением соседних кадров.

## Уточнения по источникам

- На официальном сайте найдены расписание, календарь, стоимость и School Policies на 2026–2027 учебный год. Они представлены как текущие материалы. Политики 2025–2026 вынесены в архив.
- Три свежие новости датированы 27 октября 2026 года. Они снабжены соответствующими фотографиями и ссылками на оригиналы.
- Контакты, часы работы и почта для документов совпали с заданием. Карта взята из официальной страницы контактов, ссылка на точку использует точный идентификатор объекта карты.
- Описание учебной программы по-прежнему датировано 16 августа 2022 года. KG1–KG2 и классы 1–11 также перечислены на текущей официальной странице KHDA Fact Sheet. Конкретное содержание программы, условия набора и наличие мест следует подтвердить у администрации.
- Историческая заметка о юбилее содержит противоречие между датой публикации, годом основания и числом лет. Юбилей, возраст школы и дата основания на новом сайте не заявлены.
- Стаж сотрудников не пересчитывается и не публикуется. Образование и полные должности взяты из индивидуальных профилей.
- Для формы не нужен обработчик заявок: она только открывает WhatsApp с подготовленным текстом. Пользователь сам подтверждает отправку. Веб-сайт не сохраняет данные формы и не принимает документы.
- Суммы оплаты не перепечатаны: дана ссылка на опубликованную таблицу 2026–2027. Требования к документам изложены с сохранением отличий по классам и сопровождаются оригинальными правилами.
